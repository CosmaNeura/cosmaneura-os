# Saved recording labels

Tier 1: Home recording presentation only.

The native Mac test saved 18 seconds, but every retained recording appeared as
"Private recording · Saved on this device". Selecting the first identical row
opened an older 36-second recording. Two sealed entries with no audio also
claimed to be saved recordings.

Home now includes each recording's existing saved duration. A sealed entry
without chunks says "Stopped · no audio captured". Unconfirmed physical stop
still says "Check recording status", even with no saved chunks. Reopening keeps
the exact recording ID and existing account, custody and consent checks.

Acceptance: distinguish equal titles with different durations, preserve empty
versus uncertain stop states, and open the selected ID without a notebook write.
Run the existing Home, recording and workspace regression suites, TypeScript,
renderer build and implementer review on the exact committed source.

Recovery is a source revert and renderer rebuild. There is no schema, stored
data, native helper, permission, microphone, network or transcription change.
This source fix does not qualify hardware timing or activate a new release.
