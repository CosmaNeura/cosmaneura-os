# Retained iOS PCM authority overlay

This narrow delta applies to Scribe commit `ea7f99d0278a05706531ffb1288cb1df7acf507b` through `prepare-apple-synthetic.py --renewable-native-capture`. The option defaults off. The original source is read-only; all base and result hashes are checked in the separately archived shell. Existing auth, queue, identity and signing settings are unchanged.

The renewable core and Capacitor packages declare iOS 17, matching the accepted app minimum. Xcode compiles package targets independently: leaving these declarations at iOS 15 rejects the continuous recording clock even when the app targets iOS 17. The unmodified legacy packages retain their original declarations when this overlay is disabled.

The native core admits one run ID, exact lease generation, absolute expiry, cumulative chunk window and immutable hard budget. A separate continuous clock enforces expiry during permission/startup and active recording. Heartbeats cannot renew it. Extensions preserve sequence, partial chunks and rational resampler phase. Expiry/frame exhaustion freezes input, drains accepted packets and retains a final partial for one explicit Stop. Stop or an exhausted run cannot be extended or restarted with the same run ID.

The Capacitor package advertises `getCaptureCapabilities(): {version: 1, renewableAuthority: true}` and accepts `authority: {runId, generation, expiresAtMs, hardMaximumChunks}` on Start. `extend({sessionToken, extension: {runId, generation, expiresAtMs, maximumChunks}})` confirms those exact fields and token only after the native producer accepts them. Bounds are cumulative from Start. A `window_closed` event contains the session token and `authority_expired` or `frame_limit`; the caller drains through the existing Stop contract. No PCM is embedded in that event.

`confirmCaptureIdle(): {version: 1, idle: boolean}` checks native ownership across every bridge in the process. Ownership begins before permission/startup and survives failed closure; only verified retirement releases it. The method never starts or stops input. After a lost JavaScript run, explicit recovery requires this proof before acknowledging the retained gap. Missing, malformed, failed, timed-out or superseded replies retain the recovery fence. A separate Start remains necessary to resume recording.

The shared TS source/bridge probes support before native Start, requires exact extension confirmation and drains a native window closure before notifying its caller. A missing/old plugin rejects authority-bound startup before audio. New workspace compositions using this source must explicitly include this qualified overlay. Automatic controller renewal and the full-length local service workflow are now covered by W9r/W9s; full-length app-shell and physical-device qualification remain separate. See `docs/reference/cosmasos-beta/W9_CONTINUOUS_SERVICE_CHECKPOINT.md` for current integration evidence and limits.
